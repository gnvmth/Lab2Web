# Langkah-Langkah Praktikum

## 1. Membuat Repository

Membuat repository baru di GitHub dengan nama **Lab2Web**. Repository digunakan untuk menyimpan seluruh file hasil Praktikum Pemrograman Web 2.

## 2. Membuat Tabel HTML

Pada latihan pertama dibuat tabel data mahasiswa menggunakan elemen:

- `<table>` untuk membuat tabel.
- `<tr>` untuk membuat baris.
- `<th>` untuk membuat judul/header tabel.
- `<td>` untuk membuat isi data tabel.

Kemudian tabel dikembangkan menggunakan `<caption>`, `<thead>`, `<tbody>`, dan `<tfoot>`. Pada bagian rata-rata nilai digunakan atribut `colspan`.

## 3. Membuat Form Registrasi

Dibuat form registrasi mahasiswa yang berisi nama lengkap, email, password, tanggal lahir, serta tombol Daftar dan Reset.

## 4. Radio Button dan Checkbox

Radio button digunakan untuk pilihan jenis kelamin, sedangkan checkbox digunakan untuk pilihan keahlian.

Radio button digunakan ketika pengguna hanya dapat memilih satu pilihan, sedangkan checkbox memungkinkan pengguna memilih lebih dari satu pilihan.

## 5. Select dan Textarea

Elemen `<select>` digunakan untuk memilih program studi, sedangkan `<textarea>` digunakan untuk memasukkan alamat atau teks yang lebih panjang.

## 6. Validasi Form Dasar

Validasi form menggunakan beberapa atribut HTML:

- `required` untuk membuat input wajib diisi.
- `minlength` untuk menentukan jumlah karakter minimum.
- `min` untuk menentukan nilai minimum.
- `max` untuk menentukan nilai maksimum.

## 7. Semantic HTML

Praktikum menerapkan beberapa elemen semantic HTML:

- `<header>` sebagai bagian kepala halaman.
- `<nav>` sebagai bagian navigasi.
- `<main>` sebagai konten utama.
- `<section>` sebagai bagian atau kelompok konten.
- `<article>` sebagai konten yang berdiri sendiri.
- `<aside>` sebagai informasi tambahan.
- `<footer>` sebagai bagian bawah halaman.

## 8. Multimedia

Elemen multimedia yang digunakan adalah:

- `<audio>` untuk menampilkan dan memutar file audio.
- `<video>` untuk menampilkan dan memutar file video.

File multimedia disimpan di dalam folder `media/`.
